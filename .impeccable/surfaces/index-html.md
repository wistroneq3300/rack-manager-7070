# Rack Manager surface brief

Mode: Operate. Scope: the single-page Rack Overview, Power Shelf, FW Flash, Add Tray, confirmation, toast, and HW/FW surfaces in `index.html`.

## Direction contract

THESIS: A precision semiconductor-fab control console where 14 physical trays read as stable operating rows, not promotional cards. It refuses the usual dashboard of bright status tiles and simultaneous rainbow action buttons.

OWN-WORLD: Deep graphite and blue-black planes, cool hairline dividers, one low-saturation cyan/teal interaction accent, and semantic green/amber/red only when state or risk earns it. Square-shouldered 10–12px radii, tabular numerals, calm borders, and no decorative lift or glow.

STORY: Operators identify a tray, scan each node name, verify OS/BMC connectivity and power state, then reveal the exact power action only when needed. Scope and consequence remain visible through the original confirmation flow.

FIRST VIEWPORT: A fixed operational rail and compact sticky command bar frame one full tray. Tray health sits beside the tray name; four node cells lead with name, place IP/connectivity in a legible facts block, and keep primary plus progressive actions beneath status. The signature interaction is a persistent, per-tray/per-node action disclosure that survives the 20-second DOM rebuild.

FORM: Semiconductor fab control surface, seventh grounded direction, seed `81c3943f`. The brief-pinned premium enterprise palette and safety constraints govern all open details.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Constraints

Preserve every API, action key, callback, confirmation token, guard delay, firmware selection, official logo, and 20-second refresh. Python files are read-only. Both themes, requested viewports and zoom levels, keyboard focus, explicit Partial/Offline/Unknown text, and complete IP strings are required.
